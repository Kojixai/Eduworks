# Image shortlist (Envato Elements)

The Envato tools available in this project return **watermarked previews only** and have no licence or download action, so none of these are on the site. The book cards use designed SVG covers until you license real photos. To swap one in, save the licensed image as `public/site/books/<book-id>.jpg` (landscape, about 1200 x 800) and the card picks it up automatically.
